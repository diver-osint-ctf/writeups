### Welcome to the DIVER OSINT CTF 2026!

- [Competition Rules and Regulations](https://ctfd.diverctf.org/rules)
- [About Flag Submission](https://ctfd.diverctf.org/flag_format)  

**If all members in your team agree to the rules and terms and conditions**, find the flag from `#announcement` channel on Discord and enter it here.   
Answering this correctly unlocks **6 briefing challenges** to verify imporant part of rules! Once you complete the briefing challenges, the actual challenges will be unlocked.  
Flag Format: `Diver26{flag}`

#### About hints
In this CTF, **no points will be deducted by opening hints**. Leverage them! You can see hints by clicking "Unlock Hint for 0 points" on each challenge.

#### Limit on number of attempts
There is a limit on the number of attempts per question. Be very careful with "attempts" on the challenges.  
Details are explained in [About Flag Submission](https://ctfd.diverctf.org/flag_format) page. Make sure to read this.
