# 04_attempt_limit (10pt / 860 solves)

## 問題文

問題によっては、解答試行回数に上限（attempt limit）が設定されています。  
挙動については「[Flagの提出方法について](https://ctfd.diverctf.org/flag_format)」のページを確認してください。  
これを使い果たした場合、たとえtypoによるものだったとしても、プレイヤーが運営者に対して回数のリセットを要求することはできません。  

上記を理解し、誓約する場合は以下のFlagを送信してください。Flagが送信された時点で、チーム全員が誓約したとみなします。  
`Diver26{We_understand_attempt_limits_wont_be_reset}`

Depending on the challenges, there may be a limit on the number of submission attempts.  
Please check the "[about flags](https://ctfd.diverctf.org/flag_format)" page for details on how this works.  
If you exhaust your attempts, you cannot request a reset from the organizers, even if the attempts were wasted due to a typo.

If you understand and pledge to uphold the above, please submit the following flag. By submitting the flag, all team members are considered to have pledged.  
`Diver26{We_understand_attempt_limits_wont_be_reset}`
