# telelens (337pt / 145 solves)

## 問題文

映像 / Video: https://youtu.be/3O09qFWkjBs

この動画が撮影された日はいつか。現地時間のYYYY-MM-DDで答えよ。
例えば、現地時間で2026年7月1日に撮影された場合、Flagは `Diver26{2026-07-01}` となる。

Answer the date this video was filmed in YYYY-MM-DD format based on local time.
For example, if it was filmed on July 1, 2026 (local time), the flag should be `Diver26{2026-07-01}`.


## 解法

天気の悪い、空港の駐機場が映っています。冒頭に「JGAS」と映っているので、 `JGAS airport` で検索すると、[様々な空港近くに拠点を持っている会社](https://www.jgas.com/company/profile.html)がヒットします。このうち、羽田空港最寄りの事業所（35.555537, 139.754161）と周辺の景色が一致します。衛星画像と照らし合わせると、[羽田イノベーションシティ](https://goo.gl/maps/JXeECbEt4umuJmbT9)付近で撮影された動画であると推定できます。

さて、動画には非常に多くの航空機が映り込んでいます。これらの動向や駐機場所をすべて調査して突き合わせると日付が確定するはずですが、データが膨大になってしまうので、何かよい対象がないか絞り込みたいところです。

JALやANAの機体はたくさん映っていますが、両社とも羽田を拠点としているため、データとして出現する頻度が非常に高いことが想定されます。絞り込みに使うのは極めて大変そうです。  
そこで、羽田を拠点としていない（珍しい）航空機を探してみましょう。具体的には、海外のエアラインやビジネスジェットなどがあれば最適です。

0:13ごろに赤い尾翼の航空機、0:16ごろに尾翼の模様が特徴的な航空機（前方は隠れている）、0:17ごろに緑色主体のデザインの航空機が映っています。

それぞれGoogle Lensに通すと、順にニューギニア航空、キャセイパシフィック航空、エバー航空がヒットします。  
特にニューギニア航空については同じ画角で撮影された画像がヒットするほか、「激レア」「デモフライトで飛来」といった記事や投稿がヒットします。どうやら、普段はあまり見かけない機体のようです。

- https://flyteam.jp/photo/4365911
- https://trafficnews.jp/post/644272
- https://www.hiraiki.jp/airlines/view/20502

そこで、`ニューギニア航空　羽田空港` でGoogle検索すると、航空系メディアの記事から、2026年2月にデモフライト目的で飛来したことが確認できます（また、同社が羽田に定期便として就航しているという情報も存在しません）。

- https://www.aviationwire.jp/archives/337798

また、与えられた動画では天気が悪い様子が確認できます。
東京・羽田空港の過去の気象データを参照すると、ニューギニア航空が飛来した日（2月10日～12日）のうち、降雨があるのは11日のみです。

- https://www.data.jma.go.jp/stats/etrn/view/hourly_a1.php?prec_no=44&block_no=0371&year=2026&month=02&day=11&view=p1

加えて、先程の画像検索でヒットしたFlyteamから、他の投稿を参照すると11日に撮影されたものだけ天候が悪いことが確認できます。

https://flyteam.jp/registration/P2-PGA/photo

Flag: **Diver26{2026-02-11}**
