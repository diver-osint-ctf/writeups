# arcade (100pt / 244 solves)

## 問題文

この写真の撮影地はどこか。地図上で示せ。

Where was this photo taken? Indicate its location on a map.


## 配布ファイル

- [arcade.jpg](./public/arcade.jpg)

## 解法
繁体字が見えることから、台湾ないし香港である可能性が想定できます。こうした検索ワードとともに、背景のランタンを画像検索すると遠東百貨店信義A13で撮影された写真であることがわかります。

『ひみつのアイプリ』台湾版公式サイトから[ゲーム筐体の位置を示した地図](https://www.google.com/maps/d/u/0/viewer?mid=1P745Zmt8k_ArFSN6cHFycqxa9dT2SQA&ll=25.03679999999999%2C121.56800000000001&z=19)を確認できます。また、『ポケモンメザスタ』台湾版公式サイトからも[ゲーム筐体の位置を示した地図](https://www.google.com/maps/d/u/0/viewer?mid=1P5i95AJDSdOFORq7UZdCDR3fefAplMQ&ll=25.036818499999995%2C121.5680662&z=18)を確認できます。これらの地図から、FUNBOX：信義遠東で撮影されたものであろうことがわかります。

Flag設定座標: **25.0368, 121.5680**（許容誤差: 30m）
