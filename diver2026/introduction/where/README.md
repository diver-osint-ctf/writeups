# where (100pt / 330 solves)

## 問題文

この写真の撮影地はどこか。地図上で示せ。

Where was this photo taken? Indicate its location on a map.


## 配布ファイル

- [where.jpg](./public/where.jpg)

## 解法

写真を見ると電柱番号がはっきり見えるため、ここから撮影地を特定できます。

電柱や路面にハングルが書かれていることから韓国で撮影された写真であると想定できるため、`전주 번호 검색` や `전주번호 검색`など韓国語を使ってGoogle検索してみると、[ElecMap](https://elecmap.kr/)や[For Cartographer](https://cartographer.ivyro.net/)というサイトがヒットします。

このようなサイトに、写真に記載されている `0224F9811` という番号を入力すると、撮影地を特定することができます。

Flag設定座標: **37.5424, 127.0570**（許容誤差: 30m）
