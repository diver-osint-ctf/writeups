# kohaku (100pt / 456 solves)

## 問題文

建築家・白井晟一の自邸であった虚白庵は、2010年に解体された。2026年現在、解体後の跡地に建っている店舗の名称を、店舗公式サイトに登録されている日本語表記で答えよ。
たとえば、題意を満たす店舗がマクドナルド 新宿西口店であった場合、Flagは`Diver26{マクドナルド 新宿西口店}`となる。

Kohaku-an, the former residence of architect Seiichi Shirai, was demolished in 2010. As of 2026, answer the name of the store that stands on the former site, using the Japanese spelling registered on the store's official website.
For example, if the answer is McDonald's Shinjuku Nishiguchi shop, the flag should be `Diver26{マクドナルド 新宿西口店}`.


## 解法
建築作品のうち、個人住宅にあたるものは、多くの場合住所が一般公開されません。これは虚白庵についても同様ですが、`虚白庵`と検索すると、2010年の解体直前に行われた見学会に際して書かれた[ブログ記事](http://blog.livedoor.jp/shyougaiitisekkeisi2581/archives/52119177.html)を見つけることができ、ここにはgoogle earthのスクリーンショットが掲載されています。また、[他のブログ記事](https://www.designfarm.org/dfblog/2260)を見ると、この作品が「新江古田の駅前」にあったことが記載されています。

これらの情報をもとに、google earth pro で新江古田駅周辺の過去の衛星画像を見ると、ブログから取得できる衛星画像と同様の施設を見つけることができます。また、google mapで最新の情報を見ると、ここに建つ「店舗」は[どらっぐぱぱす 新江古田駅前店](https://www.matsukiyococokara-online.com/map/?kid=20306363)に特定できることも確認できます。

Flag: **Diver26{どらっぐぱぱす 新江古田駅前店}**
