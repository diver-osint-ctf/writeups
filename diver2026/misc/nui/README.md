# nui (100pt / 242 solves)

## 問題文

写真のぬいぐるみは、いつ、どのような機材で撮影されたものか答えよ。
2020年11月23日にCanon PowerShot SX70 HSで撮影されたものであれば、Flagは`Diver26{20201123_Canon PowerShot SX70 HS}`となる。

Answer when the photo of the plush toy was taken and what equipment was used.
If it was taken on November 23, 2020, with a Canon PowerShot SX70 HS, the flag should be `Diver26{20201123_Canon PowerShot SX70 HS}`.


## 配布ファイル

- [nui.jpg](./public/nui.jpg)

## 解法
画像を検索すると、[読売新聞](https://www.yomiuri.co.jp/science/20260410-GYT1T00111/)の記事など、いくつかの報道記事がヒットします。  

この写真そのものの出所がNASAであることは報道資料に記述されているとおりであるため、[NASA公式サイト](https://www.nasa.gov/)のサイト内検索で`Orion Rise`といった、報道資料から読み取れるワードを検索します。これにより、[メタデータをそのまま残した写真を掲載したブログ記事](https://www.nasa.gov/blogs/missions/2026/03/27/artemis-ii-crew-arrives-at-launch-site-shares-moon-mascot/)を見つけることができます。  

Flag: **Diver26{20260128_Galaxy S23 Ultra}**
