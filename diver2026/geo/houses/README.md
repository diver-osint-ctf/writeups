# houses (484pt / 46 solves)

## 問題文

この写真の撮影地はどこか。地図上で示せ。

Where was this photo taken? Indicate its location on a map.


## 配布ファイル

- [houses.jpg](./public/houses.jpg)

## 解法
写真にメタデータは存在しませんが、電柱を見ると関西電力特有の腕金（cf. [https://wikiwiki.jp/geoguessr/%E9%9B%BB%E6%9F%B1/%E6%97%A5%E6%9C%AC#z9e0e8c1]）がついています。また、反射板（cf. [https://youtu.be/4kOeua7KG0s?t=1115]）からもこの電柱が関西電力のものであることが推察できます。

マンホールがはっきり映っているため、関西電力の管区内のマンホールを調べることができます。結論から言えばこれは[奈良県田原本町のマンホール](https://yamasan-aruku.com/manhole-japan-2-3-2-2/manhole-nara/)であり、唐古・鍵遺跡の復原楼閣が描かれています。

次に、この写真の方位について考えます。田原本町であることを前提に考えると、この地域の八木・宇田アンテナは[生駒山テレビ・FM送信所](https://ja.wikipedia.org/wiki/%E7%94%9F%E9%A7%92%E5%B1%B1%E3%83%86%E3%83%AC%E3%83%93%E3%83%BBFM%E9%80%81%E4%BF%A1%E6%89%80)の方角を向くことが想定されます。よって、アンテナの向きからこの写真は、東西に流れる道路を西を向いて撮影したものなのではないかと考えることができます。  

さらに、写真奥にはそこだけガードレールのついた道路が見えます。これは橋なのではないかと想定できます。さらに、この道路が撮影地点の道路から少しだけ南向きに屈曲していることも読み取れます。

これらの情報を踏まえると、田原本町を南北に流れる寺川の東岸が撮影地点であると考えられます。寺川にはいくつかの橋がかけられていますが、いずれの地点もストリートビューで確認できるため、flagが定まります。

Flag地点: **34.54261, 135.79655**（許容誤差: 20m）
