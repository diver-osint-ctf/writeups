# evacuation (318pt / 153 solves)

## 問題文

Website: https://www.desmoinesregister.com/picture-gallery/news/local/navajo-nation/2016/07/12/photos-fire-at-wpx-energy-oil-production-site-near-nageezi/87006988/

このニュースサイトに掲載されている画像 `636041110454630283-02FMN-FIRE-0715-.jpg` の撮影地点を地図で示せ。  
もし閲覧できない場合でも、調査を続行せよ。

Show the location where the image `636041110454630283-02FMN-FIRE-0715-.jpg`, featured on this news website, was taken on a map.  
Even if you are unable to view it, continue the investigation.


## 解法
問題に添付されているURLを開き、`[636041110454630283-02FMN-FIRE-0715-.jpg](https://www.desmoinesregister.com/gcdn/-mm-/3dc37cda322839919d09682e722a809cc5ccb1f6/c=0-142-2223-1398/local/-/media/2016/07/14/TXNMGroup/Farmington/636041110454630283-02FMN-FIRE-0715-.jpg)` を確認します。画像を格納しているウェブサイトは米国国外からのアクセスを遮断しているため、プレイヤーが米国IPを持っていない場合にはVPNを利用するか、あるいはdiscordに画像URLを貼り付けて展開させるといった方法を取る必要があります。

記事中の記述から、この写真がニューメキシコ州・Bloomfieldのホテルで撮影されたことがわかります。同地に所在するホテルは数軒程度しか存在しないため、これらを確認します。すると、この写真はBest Western Territorial Inn & Suitesのパティオにて撮影されたものであることがわかります。

Flag設定座標: **36.708083, -107.986156**（許容誤差: 30m）
